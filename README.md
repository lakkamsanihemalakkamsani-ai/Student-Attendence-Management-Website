# 📋 Student Attendance Dashboard

A sleek, responsive, and lightweight web application to manage and track student attendance in real-time. Built entirely using vanilla HTML, CSS (using modern custom properties/variables), and JavaScript.

## 🚀 Features

* **Real-time Statistics:** Instant calculation of Total Students, Present, and Absent counts.
* **Persistent Storage:** Uses `localStorage` so data remains safe even if you refresh or close the browser.
* **Duplicate Prevention:** Automatically blocks adding duplicate Roll Numbers.
* **Fully Responsive:** Beautiful grid and flexbox layout that works seamlessly across desktops, tablets, and mobile screens.
* **Easy Management:** Smooth toggle actions for attendance states (Present/Absent) and instant roster removal.

---

## 🛠️ Tech Stack

* **Structure:** HTML5
* **Styling:** CSS3 (Featuring CSS variables & Flexbox/Grid)
* **Logic:** JavaScript (ES6+ Vanilla)
